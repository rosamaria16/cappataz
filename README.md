# CAPPATAZ

### Tu Semana Santa, paso a paso.

Aplicación multiplataforma para consultar información, seguir la actualidad y planificar la Semana Santa de Sevilla desde un único lugar.

</div>

---

## Sobre CAPPATAZ

**CAPPATAZ** nace como Trabajo de Fin de Grado con el objetivo de facilitar el acceso a la información relacionada con la Semana Santa de Sevilla.

La aplicación reúne distintas funcionalidades de consulta, consumo de contenido audiovisual y planificación para acompañar al usuario durante la Semana Santa de una forma sencilla, accesible y centralizada.

## Funcionalidades

Entre las principales funcionalidades de la aplicación se encuentran:

- Consulta de noticias relacionadas con la Semana Santa. Si quieres echar un vistazo rápido, puedes consultar un resumen de todo elaborado mediante inteligencia artificial.
- Consulta del Programa Oficial por días y hermandades.
- Acceso a emisoras de radio cofrade.
- Herramienta de creación de un itinerario personalizado.
- Exportación en PDF del itinerario personalizado, permitiendo compartirlo con otras personas.

## Tecnologías

CAPPATAZ ha sido desarrollada utilizando principalmente:

- **Flutter**: aplicación multiplataforma.
- **FastAPI**: API y lógica del backend.
- **SQLAlchemy**: acceso y gestión de datos.
- **Neon**: base de datos en producción.
- **FastAPI Cloud**: despliegue del backend.
- **Netlify**: despliegue de la aplicación web.

## Objetivo

El proyecto nace como respuesta a una conversación donde se hablaba sobre la falta de herramientas en el mercado que facilitasen ciertas gestiones a los cofrades. Por ello, se busca ofrecer una solución que simplifique la planificación de la Semana Santa, en concreto la de Sevilla, reuniendo información que habitualmente se encuentra distribuida entre diferentes medios, páginas web y redes sociales.

CAPPATAZ pretende que personas de cualquier edad, familiarizadas con la Semana Santa o no, puedan organizar su experiencia y disfrutar de ella de una forma más cómoda.
